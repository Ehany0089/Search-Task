Standard numeric format : معناها تنسيق الارقام لعرضها علي المستخدم بطريقه مناسبه وتسهل فهم المعني من الارقام
الصيغه العامه لاستخدامها  :value.ToString("format")
مثال :
double price = 1234567.89;

Console.WriteLine(price.ToString("N2"));

في هذا المثال تعرض الارقام للمستخدم بعلامه بعد كل 3 ارقام لتوضح الالوف وعلامه(.) تفصل الكسور عن الرقم الصحيح بحيث يظهر رقمين عشريين وهو ما يعبر عنه رقم 2 بجوار حرف N :1,234,567.89

ممكن نستخدم الصيغه المختصره مثل 
nt X = 10;
int Y = 20;
Console.WriteLine($"Equation: {X} + {Y} = {X + Y:C}");
ويكون الناتج Equation: 10 + 20 = $30.00


اهم انواع (Standard numeric format)
format              الرمز
Number               N  (N2) N يظهر الرقم بفواصل الالاف 2 توضح اظهار رقمين عشريين فقط
Decimal / Integer    D  (D5) يظهر رقم مثل 45في خمس خانات 0045
Fixed-point          F   تعمل عمل N ولكن في تحديد الارقام العشريه فقط ولا تضع الفواصل الالاف
Currency             C   تظهر نوع العمله المستخدمه قبل الرقم وتظهر الرقم 30 تحوله الي$30.00
Percentage           P    تظهر علامه % مثل استخدامها في نسبه مثل رقم .06 يظهر للمستخدم 6%بحيث يضرب الرقم في 100
